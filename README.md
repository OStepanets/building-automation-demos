# Інтерактивні приклади до курсу «Автоматизація інженерних систем будівель»

Набір самодостатніх веб-сторінок, які використовуються як демонстрації на лекціях
для студентів спеціальності 151 «Автоматизація та комп'ютерно-інтегровані технології».

Кожен приклад — це працююча математична модель із повзунками: студент бачить не
готовий висновок, а поведінку системи, яку сам і змінює.

**Сайт:** https://ВАШ-ЛОГІН.github.io/building-automation-demos/

## Що всередині

| Приклад | Тема | Сторінка |
|---|---|---|
| Опалювальна крива | Нахил, паралельний зсув, обмеження, фільтрація `T` зовнішнього повітря | [`heat-substation/heating-curve.html`](heat-substation/heating-curve.html) |
| Закон регулювання | Коли Д-складова допомагає, а коли лише зношує привід | [`heat-substation/pid-law.html`](heat-substation/pid-law.html) |
| Anti-windup | Насичення інтегратора й ціна його відсутності | [`heat-substation/anti-windup.html`](heat-substation/anti-windup.html) |

Приклади у сценарії «закон регулювання» відкриваються одразу в потрібному стані
через мітку в адресі: `pid-law.html#ideal`, `#noisy`, `#dead`, `#itp`.

## Технічні особливості

- Жодних зовнішніх залежностей: ні бібліотек, ні CDN, ні шрифтів зі сторонніх доменів.
  Кожна сторінка — один HTML-файл, у якому і розмітка, і стилі, і код моделі.
- Працює з протоколу `file://` — достатньо відкрити файл подвійним кліком.
  Для аудиторії це надійніше за будь-який онлайн-варіант.
- Немає серверної частини, бази даних і збирання даних про відвідувачів.
- Моделі чисельні, дані синтетичні. Жодної прив'язки до конкретних реальних об'єктів.

## Використання офлайн

`Code → Download ZIP`, розпакувати, відкрити `index.html`. Усі посилання відносні,
тож структура папок працює однаково локально й на сайті.

## Публікація власної копії

1. Створити публічний репозиторій.
2. `Add file → Upload files` — перетягнути вміст цієї папки.
3. `Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)`.
4. Через одну-дві хвилини сайт доступний за адресою `https://ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

GitHub Actions вимикати не можна: публікація «з гілки» виконується службовим
робочим процесом `pages build and deployment`, і без Actions сайт не оновлюватиметься.
Натомість у `Settings → Actions → General` варто обмежити дозволи —
залишити лише дії самого GitHub і встановити режим «лише читання»
для `Workflow permissions`.

## Про авторство та використання ШІ

Концепція курсу, методичний задум, структура й послідовність викладу, добір прикладів,
сценарії демонстрацій, інженерний зміст і його фахова перевірка належать автору.

Для підготовки матеріалів використовувався Claude (Anthropic) — як інструмент
реалізації: програмування розрахункових моделей, верстка сторінок, оформлення.
Усі змістовні й методичні рішення, а також перевірку відповідності інженерній
практиці та чинним нормативним документам виконав автор.
